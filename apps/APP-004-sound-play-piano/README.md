# 音あそびピアノ

1歳前後の子どもが、7色の大きな鍵盤をタッチして音と視覚演出を楽しむWebアプリです。正解・不正解や曲の演奏を目的にせず、自由なタッチ、複数指、指を滑らせる操作に対応します。

## 起動方法

外部ライブラリやビルドは不要です。`index.html` をブラウザで直接開くか、このフォルダでローカルサーバーを起動します。

```sh
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。同一ネットワーク上のスマートフォンで確認する場合は、PCのローカルIPアドレスを使ってアクセスしてください。

## ファイル構成

- `index.html` — 画面の基本構造
- `style.css` — 7色鍵盤、縦横レスポンシブ表示、アニメーション
- `script.js` — 鍵盤生成、Pointer Events、Web Audio API、状態管理
- `README.md` — 起動方法と確認項目

## Web Audio APIの概要

最初に音が必要なユーザー操作を受けた時に `AudioContext` を作成または再開します。各音は柔らかい `triangle` OscillatorとGainNodeで作り、短いアタックの後、約0.8秒で自然に減衰させます。音量はmaster Gainで控えめにし、同時発音を最大5音に制限しています。終了したAudioNodeは切断し、追跡配列から削除します。

音声オフ時にも鍵盤と装飾は動作します。設定は `localStorage` に保存され、オンへ戻すボタン操作自体では音を鳴らしません。

## 確認項目

- ド〜シの7鍵盤が順番に表示され、それぞれ異なる高さで鳴る
- タッチ、マウス、スタイラスで即座に反応する
- 複数指で同時に演奏できる
- 押したまま別の鍵盤へ滑らせると、新しい鍵盤だけが鳴る
- 連打でき、同時発音は最大5音に制限される
- 音声オフでも押下表示、音符・丸、7回ごとの特別演出が動く
- 音声設定が再読み込み後にも保持される
- 縦向きでは鍵盤が縦、横向き・広い画面では横に並ぶ
- `prefers-reduced-motion` で装飾移動が短くなる
- 操作後に装飾DOMとAudioNodeが残り続けない
