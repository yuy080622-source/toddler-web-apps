# できたよ！生活習慣

1〜2歳ごろの子どもが、保護者と一緒に「手洗い」「歯磨き」「お片付け」をまねして遊ぶWebアプリです。失敗、減点、時間切れはありません。画像や音声素材がなくても、絵文字・CSS・ブラウザの読み上げ機能で最後まで遊べます。

## 起動方法

### いちばん簡単な方法

`index.html` をダブルクリックし、ブラウザで開きます。

### ローカルサーバーを使う方法

このフォルダで次を実行し、表示されたURL（通常は `http://localhost:8000`）をブラウザで開きます。

```bash
python3 -m http.server 8000
```

音声読み上げは、ブラウザの仕様により最初に画面を触った後から始まります。SafariやChromeの新しいバージョンを推奨します。

## 遊び方

- 手洗い：蛇口、石けん、手、タオルを順にタップします。「ごしごし」は連続タップでも、こする操作でも進みます。
- 歯磨き：口をタップして歯ブラシを持ち、続けて口を連続タップ、または左右にこすります。
- お片付け：4つのおもちゃをタップすると箱へ入ります。箱へドラッグして入れることもできます。箱以外で離した場合は元へ戻ります。
- 3秒ほど操作がないと、次に触るものがやさしく光ります。
- 右上のボタンで音をオン・オフできます。設定は同じブラウザに保存されます。

## 素材の差し替え方法

現在は素材不要で動くよう、絵文字とCSS図形を使っています。将来素材を追加するときは、画像を `assets/images/` の該当フォルダ、音声を `assets/sounds/` に置いてください。

画像を使う場合は `index.html` または `script.js` 内の絵文字を `<img>` に置き換え、必ず内容に合った `alt` または `aria-label` を設定します。案内音声を使う場合は、`script.js` の `speak()` より先に音声ファイルの再生を試し、読み込みに失敗したら現在のWeb Speech APIへ戻る構成にしてください。

## 確認項目

- ホームから3つの遊びを開始できる
- 全モードをタップだけで完了できる
- 手洗い・歯磨きでこする操作が反応する
- お片付けでタップとドラッグが使える
- 連打してもステップが二重に進まない
- 途中でホームへ戻っても音声やタイマーが残らない
- 完了後に「もういちど」「おうちへ」が使える
- 音声設定が再読み込み後も保持される
- 3秒後にヒントが表示される
- スマートフォン縦向き、タブレット、PCで主要操作が画面内に収まる
- OSの「視差効果を減らす」設定でアニメーションが抑えられる

## 対応と注意

Pointer Events、safe area、`100dvh`、`prefers-reduced-motion` に対応しています。読み上げ音声の声質や利用可否は端末・ブラウザによって異なり、利用できない場合も視覚表示のみで遊びを継続できます。個人情報、広告、外部通信、アクセス解析は使用しません。
