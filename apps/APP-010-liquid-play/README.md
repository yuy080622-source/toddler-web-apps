# APP-010 ぷにぷにジェリー（仮）

画面全体で、顔のある3色のやわらかい半固形ジェリーキャラクターを、端末の傾きまたは長押し位置への引力で動かすMVP試作です。管理IDと既存URLを維持するため、ディレクトリ名は`APP-010-liquid-play`のままです。

## 起動

静的ファイルのみで動作します。`index.html`をHTTPサーバー経由で開いてください。

## 操作

- 対応端末：端末を傾ける
- センサー非対応・拒否・値を取得できない場合：画面を約0.18秒以上長押しする
- iOSで許可APIが必要な場合だけ、画面上部に保護者向けの許可ボタンを表示する

傾きと長押しは共通の力ベクトルへ変換します。複数指は重心1点へ正規化し、力を加算しません。

## 表現

- 3体を少数のベジェ曲線で描き、合体・分裂させない
- 半透明の多段グラデーション、内部のぼかしたハイライト、やわらかい輪郭で厚みのあるジェリー感を出す
- 移動方向へ穏やかに伸び、方向転換中は一時的に丸みを増して、角速度を制限しながら新方向へ向く
- 壁・キャラクター同士の接触や方向転換では、小さな`jellyPulse`で「ぷるん」「むにっ」と広がる
- 顔は小さく控えめにし、輪郭の伸縮・圧縮へ追従させつつ世界座標でほぼ正立させる

厳密な自然流体や、反対方向への切り返しで角度を瞬時に切り替える表現は目標にしません。回転はキャラクターらしい穏やかな身振りとして許容し、高速回転、上下反転した顔、硬い反射、細長い紐状変形を避けます。

通常時の傾き加速度72、最大速度126は初版比約1.5倍のまま維持しています。reduced-motionでは速度上限36、尾なし、伸び・回転・弾性パルスを抑えた低刺激版で遊びを継続します。
