# APP-010 リキッドあそび（仮）

画面全体を液体世界にして、3色の大きな液体玉を端末の傾き、または長押し位置への引力でゆっくり動かすMVP試作です。

## 起動

静的ファイルのみで動作します。`index.html`をHTTPサーバー経由で開いてください。

## 操作

- 対応端末：端末を傾ける
- センサー非対応・拒否・値を取得できない場合：画面を約0.18秒以上長押しする
- iOSで許可APIが必要な場合だけ、画面上部に保護者向けの許可ボタンを表示する

傾きと長押しは共通の力ベクトルへ変換します。複数指は指位置の重心1点へ正規化し、力を加算しません。液体玉は軽量な円／楕円描画で、合体・分裂を行いません。
