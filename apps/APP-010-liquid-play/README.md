# APP-010 リキッドあそび（仮）

画面全体を液体世界にして、顔のある3色の大きなスライム状液体玉を端末の傾き、または長押し位置への引力で動かすMVP試作です。

## 起動

静的ファイルのみで動作します。`index.html`をHTTPサーバー経由で開いてください。

## 操作

- 対応端末：端末を傾ける
- センサー非対応・拒否・値を取得できない場合：画面を約0.18秒以上長押しする
- iOSで許可APIが必要な場合だけ、画面上部に保護者向けの許可ボタンを表示する

傾きと長押しは共通の力ベクトルへ変換します。複数指は指位置の重心1点へ正規化し、力を加算しません。液体玉は速度方向へ遅れて伸びるベジェ曲線のしずく形で、先頭に引かれて後端が遅れてついてくる形状状態を持ちます。減速・方向転換後も尾と向きが少し流れ残り、壁・液体同士の接触では横へ広がります。静止時には低周波の小さな不定形変化を加えています。顔は同じCanvas変形座標内で描き、輪郭の向き・伸縮・圧縮へ一緒に追従します。合体・分裂は行いません。

2026-08-30の実機改善版では、通常時の傾き加速度を48から72、最大速度を84から126へ変更し、入力応答も強めました。reduced-motion側の速度上限と刺激低減値は維持しています。

同日の液状感強化版では物理速度を維持したまま、伸び上限、後端の遅れ、遅延復元、低周波ゆらぎ、壁・液体接触の圧縮量を強化しました。物理境界と表示内補正の余白も統一し、壁接触変形が確実に発火するよう修正しています。
