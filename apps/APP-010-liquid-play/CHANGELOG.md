# CHANGELOG

## 2026-08-30 — 反転時のneutral形状を明確化

- 反転を`shrinking`、`neutral`、`switched`、`normal`のphaseへ段階化
- shrinking中は旧`shapeAngle`を完全固定し、`stretch`、`tailLag`、`wobble`を厳しい閾値まで減衰
- neutralでは伸び・尾・揺れをゼロに固定し、固定の前後非対称、上下差、`poolLean`、低周波方向差を描画から除外
- ほぼ丸いneutral形を通常時約84ms、reduced-motion時約50ms維持してから、新方向へゼロ伸長のまま一度だけ角度を切替
- switched形を短く維持し、次フレーム以降にneutral形を解きながら再伸長
- 停止復元、後端遅れ、接触時の横広がりを小幅強化し、伸び上限と速度1.5倍は維持
- 反転途中の方向変更・長押し解除、全反転方向、neutral保持時間と形状値を回帰テストへ追加
- GitHub Pagesデプロイと公開版の3画面サイズ、3玉表示、不要スクロール、コンソールを確認

## 2026-08-30 — 反転時の形状回転修正

- 約133度以上の方向差をほぼ反対方向の切り返しとして検出
- 反転中は旧`shapeAngle`を固定し、`stretch`と`tailLag`を十分に縮めてから新方向へ切り替える段階制御を追加
- 約90度の方向変更は反転扱いせず、従来の連続した形状追従を維持
- 顔を輪郭の回転座標から分離し、伸縮・圧縮へ追従しながら世界座標で正立する描画へ変更
- 先端伸び、後端遅れ、遅延復元、壁接触時の広がりを小幅に強化
- 中断時に一時的な反転状態を破棄し、BFCache復帰後の残留を防止
- 左右・上下・斜め反転、90度旋回、連続切り返し、長押し切替、reduced-motionの自動テストを追加
- GitHub Pages公開版の3画面サイズ、3玉表示、不要スクロール、コンソールを確認
- 通常速度1.5倍、3玉、Canvas 1枚、単一RAF、合体・分裂なしを維持

## 2026-08-30 — 液状感の追加強化

- 移動時の伸び上限と先頭・後端の差を広げ、加速・長押し・方向転換時の伸びを明確化
- 後端の遅れ状態を追加し、減速・方向転換後に短く尾が流れ残る表現を追加
- 形状の縮みと向きの追従を遅くし、すぐ丸へ戻らない復元へ調整
- 静止時へ約1〜2秒周期の小さな低周波ゆらぎを追加し、完全な円／楕円を回避
- 玉ごとに前後幅・高さ・上下頂点の固定差を追加し、停止時にも控えめな非対称輪郭を維持
- 壁・液体接触の圧縮量と持続を強め、接触時の横方向への広がりを明確化
- 物理境界と表示補正の余白差により壁変形が発火しにくかった問題を修正
- 顔を小型化して透明度を下げ、目幅・口幅・中心位置の伸縮追従を強化
- 通常速度1.5倍、3玉、単一RAF、reduced-motion低刺激値を維持

## 2026-08-30 — 実機フィードバック改善版

- 円／楕円中心の輪郭を、速度方向へ伸びて遅れて戻る4区間ベジェ曲線のしずく形へ変更
- 方向転換時の小さなぷる戻り、壁接触・液体同士の接触に応じた圧縮を追加
- 通常時の傾き加速度を48から72、最大速度を84から126へ変更し、力ベクトルの応答を0.12から0.16へ調整
- reduced-motionの加速度、最大速度、反発、変形量は従来の低刺激水準を維持
- 各液体玉へ目2つと小さな口をCanvas描画し、輪郭と同じ回転・変形座標へ追従
- 高速操作、複数指、`pointercancel`、回転、中断・復帰、2分相当連続動作の回帰テストを更新
