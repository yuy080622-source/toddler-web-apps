# シャボン玉タッチ

## アプリ概要

画面下から浮かぶ大きなシャボン玉をタッチすると、やさしい「ポン」という音と光の粒とともに割れる、1歳前後の子ども向けWebアプリです。正解・制限時間・ゲームオーバーはありません。

## 対象年齢

1歳前後の子どもと、その保護者を想定しています。

## 使用技術

- HTML
- CSS
- JavaScript
- Web Audio API（外部音源なし）

外部画像、外部ライブラリ、フレームワーク、Canvasは使っていません。

## 起動方法

もっとも簡単な方法は `index.html` をWebブラウザで開くことです。

ローカルサーバーを使う場合は、このフォルダで次のコマンドを実行し、表示されたアドレスをブラウザで開きます。

```bash
python3 -m http.server 8000
```

## 操作方法

- 浮かんでくるシャボン玉を指でタッチ、またはマウスでクリックします。
- キーボードでは、Tabキーで泡を選び、Enterキーかスペースキーで割れます。
- 右上の丸い「おと」ボタンで、効果音のオン・オフを切り替えます。
- 数はページを再読み込みすると0に戻ります。

ブラウザの安全仕様により、音は最初のタッチ操作のあとに再生可能になります。

## 調整方法

主な設定は `js/script.js` の先頭にある `CONFIG` にまとまっています。

### 生成間隔

- `minSpawnDelay`: 最短の生成間隔（初期値 700ミリ秒）
- `maxSpawnDelay`: 最長の生成間隔（初期値 1100ミリ秒）

### 最大表示数

- `maxBubbles`: 同時に表示する最大数（初期値 10）

### 大きさ

- `minSize`: 最小サイズ（初期値 72px）
- `maxSize`: 最大サイズ（初期値 130px）

### 色

`js/script.js` の `BUBBLE_COLORS` に色の組み合わせを追加・変更します。色はCSSで使える `rgba(...)` などで指定します。

### 効果音

`js/script.js` の `playPopSound()` を調整します。

- `oscillator.frequency`: 音の高さ
- `gain.gain`: 音量（初期値の最大は 0.075）
- `oscillator.stop(...)`: 音の長さ
- `filter.frequency`: 音の柔らかさ

音量を急に大きくすると子どもを驚かせるため、少しずつ調整してください。

## GitHub Pagesで公開する基本手順

1. GitHubで新しいリポジトリを作ります。
2. このフォルダ内の4ファイルとフォルダ構成をリポジトリへ追加します。
3. GitHubのリポジトリ画面で **Settings → Pages** を開きます。
4. **Deploy from a branch** を選び、公開するブランチ（通常は `main`）と `/ (root)` を選びます。
5. 保存し、表示された公開URLを開いて確認します。

このプロジェクトからGitHubへのpushや公開は行っていません。

## 現在の制限事項

- 遊んだ数や音の設定は保存しません。再読み込みすると初期状態に戻ります。
- 古いブラウザなど、Web Audio APIがない環境では音が鳴りません。泡のアニメーションは動きます。
- 実機やブラウザによって音色・絵文字の見た目が少し異なります。
- 泡は重なりを減らす工夫をしていますが、上昇中に一部重なることはあります。
- インストール型アプリ、オフラインキャッシュ、利用記録には対応していません。

## 初心者が最初に読む場所

まず `index.html` で画面の部品を確認し、次に `js/script.js` の `CONFIG` と `initializeApp()`、`createBubble()`、`popBubble()` の順に読むと、全体の流れをつかみやすくなります。見た目を変えたい場合は `css/style.css` の `.bubble` を確認してください。
