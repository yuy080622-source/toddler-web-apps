# くだものポン！

1歳前後の子どもと保護者が、果物へのタッチとやさしい反応を短時間楽しむためのWebアプリです。正解・不正解やスコアはありません。

## 起動方法

`index.html` をブラウザで開くだけでも動作します。音声素材やブラウザ読み上げを安定して使うには、`fruit-pop` フォルダでローカルサーバーを起動してください。

```sh
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## 構成

- `index.html`：画面構造
- `style.css`：レイアウト、配色、4種の演出、スマートフォン対応
- `script.js`：果物データ、切り替え、音声、連打制御、素材フォールバック
- `assets/images/`：任意の果物画像
- `assets/sounds/`：任意の名前音声

外部ライブラリ、広告、通信、アクセス解析は使用していません。音声設定だけを端末の `localStorage` に保存します。

## 素材の差し替え

次の名前で素材を配置すると、自動で絵文字・読み上げから素材へ切り替わります。

| 果物 | 画像 | 音声 |
|---|---|---|
| りんご | `assets/images/apple.webp` | `assets/sounds/apple.mp3` |
| バナナ | `assets/images/banana.webp` | `assets/sounds/banana.mp3` |
| いちご | `assets/images/strawberry.webp` | `assets/sounds/strawberry.mp3` |
| ぶどう | `assets/images/grape.webp` | `assets/sounds/grape.mp3` |

- 画像は正方形に近く、背景が透明なWebPを推奨します。
- 音声は短く、音量をそろえたMP3を推奨します。
- 画像がない場合は絵文字、音声がない場合はWeb Speech APIの日本語読み上げを使います。どちらも使えなくても視覚演出は動きます。
- 別のファイル名を使う場合は、`script.js` 冒頭の `fruits` 配列を変更してください。

## 確認項目

- 起動時にりんごが表示される
- 果物を触ると名前、固有の動き、8個の装飾が約700ms表示される
- 「まえ」「つぎ」で4種類が循環する
- 切り替えると途中の演出と音声が止まる
- 素早く連打しても演出が再開始され、音声や装飾が重ならない
- 音声ボタンでオン・オフでき、再読み込み後も設定が保持される
- 素材なしで絵文字とWeb Speech APIへ切り替わる
- タブ非表示、途中退出、BFCache復帰時に古い演出・音声・タイマーが残らない
- 390×844、844×390、1024×768で縦横スクロールせず操作できる
- 「視差効果を減らす」等の設定時に動き、粒子数、移動距離が弱くなる

## 公開前検証

2026年8月23日に、4種類の切替と固有演出、画像・MP3未配置時のフォールバック、100回の高速タップ、音OFF保存、キーボード操作、途中退出・BFCache復帰、3画面サイズ、コンソールを確認しました。コード上の公開前検証はPASSで、スマートフォン実機確認用の公開候補です。

実際の複数指、Web Speech APIの日本語音声・音量、safe area、reduced-motion、幼児本人の操作感、長時間利用時の発熱は実機確認が必要です。

### PM判断待ち

「まえ」「つぎ」は64px以上の大きなボタンで、4種類を確実に切り替えられます。一方、1歳前後の子どもには果物以外の操作対象となり、意図しない切替の原因にもなり得ます。削除、保護者操作への分離、スワイプ等への変更は行わず、現在の方式を維持したままPM判断待ちとしています。

## 補足

ブラウザは、音声再生をユーザー操作後にだけ許可する場合があります。本アプリの読み上げは果物を触ったときに開始するため、その制限に沿っています。
