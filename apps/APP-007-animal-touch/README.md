# 動物タッチWebアプリ

1歳前後の子どもが、4匹の動物をタッチして鳴き声とアニメーションを楽しむシンプルなWebアプリです。外部ライブラリや外部通信は使用していません。

## 起動方法

`index.html` をWebブラウザで開いてください。ローカルサーバーを使う場合は、このフォルダで任意の静的サーバーを起動し、表示されたURLへアクセスします。

## ファイル構成

```text
index.html             画面の内容
css/style.css          配色・レイアウト・アニメーション
js/script.js           タッチ操作・音声・音声オン／オフ
assets/images/         差し替え用の動物画像
assets/sounds/         鳴き声ファイル
README.md              この説明書
```

## 動物画像の差し替え

初期状態では著作権上安全な絵文字を使用しています。画像へ変更する場合は、利用許可のある画像を `assets/images/` に置き、`index.html` の該当する絵文字部分を次のように変更します。

```html
<span class="animal-picture" aria-hidden="true">
  <img src="assets/images/dog.png" alt="">
</span>
```

画像がカード内に収まるよう、必要に応じて `css/style.css` に次を追加してください。

```css
.animal-picture img {
  width: 100%;
  height: 100%;
  object-fit: contain;
}
```

## 鳴き声の差し替え

次のファイル名でMP3を `assets/sounds/` に置きます。

- `dog.mp3`（犬）
- `cat.mp3`（猫）
- `elephant.mp3`（象）
- `tiger.mp3`（虎）

MP3がない、または再生できない場合は、対応ブラウザで日本語の音声読み上げに自動で切り替わります。端末やブラウザの設定により、読み上げ音声の声質は異なります。

## 操作方法

- 動物カードをタッチ：鳴き声と動物ごとのアニメーションを再生
- 右上の音ボタン：鳴き声のオン／オフを切り替え
- 右上の音ボタンを2秒長押し：保護者設定を表示
- キーボード操作：Tabキーでカードを選び、EnterキーまたはSpaceキーで再生
- 鳴き声は連打時でも500ミリ秒以上の間隔を空けて再生されます。アニメーションは毎回動きます。

## 保護者設定

- 初期設定は10分です。
- 最初に動物をタッチしたときから時間を計測します。
- 「5分」「10分」「制限なし」から遊ぶ時間を選べます。
- 時間になると「きょうは おしまい」画面になり、動物と音声が停止します。
- おしまい画面の鍵ボタンを2秒長押しすると、保護者設定を開けます。
- 「遊びを再開」を押すと通常画面へ戻ります。
- 選択した時間はブラウザに保存されますが、残り時間は保存されません。
- 1日1回、起動時に端末の音量確認を表示します。
- 保護者設定で、今日遊んだ時間、合計タッチ数、動物別タッチ数、よく遊んだ動物を確認できます。
- 今日の記録は保護者設定から削除できます。
- 利用記録は端末内のブラウザだけに保存され、外部へ送信されません。

Webアプリだけではホーム画面への移動や端末のボタン操作を完全には防げません。必要に応じて、iPhone・iPadの「アクセスガイド」またはAndroidの「画面固定」を併用してください。

今日の記録は簡単な利用状況の目安です。発達や能力の評価・診断には使用しないでください。
