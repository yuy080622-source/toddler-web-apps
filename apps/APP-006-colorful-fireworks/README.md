# カラフル花火

## アプリ概要

画面の好きな場所をタッチすると、その位置からカラフルな光の粒が広がる、1歳前後の子ども向けWebアプリです。文字を読んだり正解を選んだりせず、触れるとすぐに色・動き・優しい音で反応します。

対象年齢は1歳前後です。必ず保護者と一緒にお楽しみください。

## 使用技術

- HTML
- CSS
- JavaScript
- Canvas API
- Web Audio API

外部ライブラリ、外部画像、外部音源、CDNは使用していません。

## 起動方法

最も簡単な方法は `index.html` をダブルクリックし、ブラウザで開くことです。基本機能はそのまま動作します。

ローカルサーバーを使う場合は、このフォルダで次のコマンドを実行し、表示されたアドレスをブラウザで開きます。

```bash
python3 -m http.server 8000
```

## 操作方法

- 画面の好きな場所をタッチ、またはクリックすると花火が開きます。
- 右上の大きな丸いボタンで音のオン・オフを切り替えます。
- キーボードの Enter またはスペースキーで、画面中央に花火を出せます。
- 音をオフにした設定は端末内に保存され、次に開いたときも維持されます。
- 回数やスコアは表示せず、自由に何度でも遊べます。

## カスタマイズする場所

### 花火の色を変える

`js/script.js` の `COLOR_PALETTES` を編集します。1つの配列が1回の花火で使う2〜3色です。

```js
const COLOR_PALETTES = [
  ["#ff78b5", "#ffe46e", "#fff1c7"]
];
```

### 粒の数を変える

`js/script.js` の次の値を変更します。

- `NORMAL_PARTICLE_COUNT`: 通常時の粒の数（初期値36）
- `REDUCED_PARTICLE_COUNT`: 動きを減らす設定時の粒の数（初期値18）
- `MAX_PARTICLES`: 画面内に残せる粒の最大数（初期値200）
- `MAX_CONCURRENT_SOUNDS`: 同時に鳴らせる効果音の上限（初期値4）

端末の負荷を抑えるため、`MAX_PARTICLES` を大きくしすぎないでください。

### 効果音を変える

`js/script.js` の `playPopSound()` を編集します。

- `oscillator.frequency`: 音の高さ
- `gain.gain`: 音量と消え方
- `oscillator.stop`: 音の長さ

幼児向けのため、音量を急に大きくしたり、高い音や長い音にしたりしないことをおすすめします。

## GitHub Pagesで公開する基本手順

1. GitHubで新しいリポジトリを作成します。
2. このフォルダ内のファイルをリポジトリへ追加してpushします。
3. リポジトリの **Settings** → **Pages** を開きます。
4. **Build and deployment** のSourceで **Deploy from a branch** を選びます。
5. 公開するブランチ（通常は `main`）と `/ (root)` を選び、保存します。
6. 数分後に表示される公開URLへアクセスします。

## 動きを減らす設定

OSやブラウザで「視差効果を減らす」などを有効にすると、粒を36個から18個へ減らし、移動距離、光跡、発光、表示時間を抑えます。タッチによる花火自体は引き続き楽しめます。

## 安全性と中断時の動作

- 効果音は控えめな音量で、同時再生を最大4音に制限しています。
- 音をオフにしても、花火の表示は通常どおり動作します。
- タブ切り替えやバックグラウンド化の間は、花火・効果音を停止して粒を破棄します。
- 画面へ戻ると、アニメーションループを1つだけ再開します。

## 現在の制限事項

- 音の設定だけを端末内に保存します。花火回数や個人情報は記録しません。
- ブラウザのプライベートモードなどで保存できない場合は、再読み込み後に初期状態の音ありへ戻ることがあります。
- ブラウザや端末により、絵文字の見た目が少し異なります。
- Web Audio APIが使えないブラウザでは音は鳴りませんが、花火は動作します。
- Canvas APIが使えない非常に古いブラウザでは花火を表示できません。
- 多数の指で極端に高速連打した場合、粒は古いものから削除され最大200個に保たれます。
- iPhone・Android実機での音量、発熱、複数指、幼児本人の刺激の感じ方は公開前に実機確認が必要です。
