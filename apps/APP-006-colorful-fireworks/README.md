# カラフル花火

画面上部のホームアイコンは、約2秒長押しした場合だけRepositoryルートの共通ポータルへ戻ります。短押しや途中解除では戻らず、花火の操作へイベントを伝播しません。

## アプリ概要

画面の好きな場所をタッチすると、画面下から小さな光が打ち上がり、タッチ位置付近でカラフルな花火が開く、1歳前後の子ども向けWebアプリです。文字を読んだり正解を選んだりせず、触れるとすぐに色・動き・優しい音で反応します。

対象年齢は1歳前後です。必ず保護者と一緒にお楽しみください。

## 使用技術

- HTML
- CSS
- JavaScript
- Canvas API
- Web Audio API

外部ライブラリ、外部画像、外部音源、CDNは使用していません。

## 操作方法

- 画面の好きな場所をタッチ、またはクリックすると、画面下から光が打ち上がり、タッチ位置付近で花火が開きます。
- 右上の大きな丸いボタンで音のオン・オフを切り替えます。
- キーボードの Enter またはスペースキーで、画面中央付近へ花火を打ち上げます。
- 音をオフにした設定は端末内に保存され、次に開いたときも維持されます。
- 回数やスコアは表示せず、自由に何度でも遊べます。

## 打ち上げ演出

2026-08-23のPM判断に基づき、従来の「タップ位置で即座に花火が開く」方式から、「画面下から打ち上がってから花火が開く」方式へ改善しました。

### 目的

- 打ち上げ花火としての全体像を幼児にも視覚的に分かりやすくする。
- タップ→打ち上げ→開花の因果関係を保ちつつ、反応の速さを損なわない。
- リアルな地面表現は追加せず、自由遊びのシンプルさを維持する。

### 確定仕様

- 打ち上げ開始位置は画面下端より少し下とし、地面・街並み等は表示しない。
- 横方向の到達位置はタップしたX座標を基本とする。
- 縦方向の爆発位置はタップY座標を基本とするが、画面端で不自然にならないよう安全範囲へ補正する。
- 上端では画面上端から約10%より下を目安とする。
- 下端では画面高さの約70%より上を最低爆発高度の目安とする。
- 画面下部をタップしても横位置は維持し、縦位置だけ最低爆発高度まで持ち上げる。
- タップ直後に打ち上げ反応を開始する。無反応時間を作らない。
- 打ち上げ時間は通常約0.3〜0.5秒を目安とする。
- 演出は「細い線」ではなく、小さな光の玉＋短い尾を基本とする。
- 上昇音は追加しない。既存の花火効果音のみを維持する。
- 複数指・連打を受け付けるが、打ち上げ中の光・尾・タイマー・AudioNodeを残留させない。
- 既存の最大粒子数200、同時効果音最大4音、音OFF保存、中断・復帰処理を維持する。
- `prefers-reduced-motion`時は、打ち上げ時間・移動・尾を短くし、既存の粒子数・寿命・発光低減も維持する。

### 実装方式

- 打ち上げ中でもタップ直後に視覚反応が始まり、「押したのに反応しない」と感じさせない。
- 低い位置で花火が開く不自然さを避ける一方、タップ位置との関係を失わない。
- 打ち上げ演出を追加しても、強い点滅、全画面フラッシュ、突然の大音量を追加しない。
- 打ち上げ光はCanvas内の配列で管理し、最大12個に制限する。完了、中断、退出、画面サイズ変更時に破棄する。
- タイマーや一時DOMは追加せず、既存の`requestAnimationFrame`ループ内で打ち上げから開花までを更新する。
- 地面の追加は今回の改善範囲外とする。

### Before / After記録

改善前のiPhone画面録画を取得済み。旧仕様は「タップ位置で直接花火が開く」。新仕様実装後、同程度の長さで上部・中央・下部タップを含むAfter動画を取得し、比較する。

## カスタマイズする場所

### 花火の色を変える

`js/script.js` の `COLOR_PALETTES` を編集します。1つの配列が1回の花火で使う2〜3色です。

### 粒の数を変える

`js/script.js` の次の値を変更します。

- `NORMAL_PARTICLE_COUNT`: 通常時の粒の数（初期値36）
- `REDUCED_PARTICLE_COUNT`: 動きを減らす設定時の粒の数（初期値18）
- `MAX_PARTICLES`: 画面内に残せる粒の最大数（初期値200）
- `MAX_LAUNCHES`: 同時に表示できる打ち上げ光の上限（初期値12）
- `MAX_CONCURRENT_SOUNDS`: 同時に鳴らせる効果音の上限（初期値4）

端末の負荷を抑えるため、`MAX_PARTICLES` を大きくしすぎないでください。

### 打ち上げ時間や尾を変える

`js/script.js` の`launchFirework`内に通常時320〜480ms、動きを減らす設定時170〜230msの時間があります。尾の長さと丸い光の数は`drawLaunches`内の`tailLength`と`tailDots`で調整できます。

## 動きを減らす設定

OSやブラウザで「視差効果を減らす」などを有効にすると、粒を36個から18個へ減らし、移動距離、光跡、発光、表示時間を抑えます。打ち上げ演出は時間を170〜230msへ短縮し、横揺れを止め、尾を短くします。タッチ直後の反応と花火自体は引き続き楽しめます。

## 安全性と中断時の動作

- 効果音は控えめな音量で、同時再生を最大4音に制限しています。
- 音をオフにしても、花火の表示は通常どおり動作します。
- タブ切り替えやバックグラウンド化の間は、花火・打ち上げ演出・効果音を停止して一時状態を破棄します。
- 画面へ戻ると、アニメーションループを1つだけ再開します。

## 利用分析

PRJ-003共通のMicrosoft ClarityとGoogle Analytics 4測定ID`G-M5FPMG34LE`を共通スクリプトから読み込みます。GA4は標準ページ計測のみで、カスタムイベント、ユーザーID、タップ位置、入力内容は送信しません。分析スクリプトを取得できない環境でも、花火・音・操作は独立して動作します。

## 現在の制限事項

- 音の設定だけを端末内に保存します。花火回数や個人情報は記録しません。
- ブラウザのプライベートモードなどで保存できない場合は、再読み込み後に初期状態の音ありへ戻ることがあります。
- Web Audio APIが使えないブラウザでは音は鳴りませんが、花火は動作します。
- Canvas APIが使えない非常に古いブラウザでは花火を表示できません。
- 多数の指で極端に高速連打した場合も、粒は古いものから削除され最大200個に保つ。
- 打ち上げ演出のコード検証は完了していますが、実際の見え方、音量、刺激、複数指操作、発熱はiPhone等の実機で再確認が必要です。
