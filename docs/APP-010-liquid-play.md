# APP-010 ぷにぷにジェリー（仮）

更新日：2026-09-03

状態：MVP試作実装済み・半固形ジェリー表現を実機改善中

注記：管理ID、既存URL、ディレクトリ名`APP-010-liquid-play`は維持する。本書をAPP-010の現行仕様の正本とする。

## 目的

スマートフォン画面全体を遊び場にし、3色のやわらかい半固形ジェリーキャラクターが、傾きや長押しの引力に応じて「ぷにっ」「ぷるん」と動く感覚遊びを作る。厳密な自然流体の再現ではなく、幼児が変化に気づきやすく、見ていて心地よいキャラクター表現を優先する。

## 対象と基本体験

- 主な対象年齢は1歳前後から。スマートフォンを優先し、縦横画面とタブレットにも対応する。
- Canvas 1枚へ、顔のある3色の大きなジェリーを3体表示する。
- 見た目の役割は赤＝大、青＝中、黄＝小とし、半径比を`1.35 : 1 : 0.8`とする。青の基準半径は画面短辺に応じて60〜93pxとし、黄も顔と内部ハイライトを視認できる大きさを保つ。
- 第一操作は端末の傾き。センサー非対応、拒否、値欠落、異常の場合は、約0.18秒以上の長押し位置へ寄る操作へ安全に切り替える。
- 複数指は位置の重心1点へ正規化し、力を加算しない。指を離した後は短い慣性を残す。
- 長押し引力が成立している間だけ、指位置または複数指の重心へ薄いオーラと穏やかな波紋を1組表示する。傾きだけでは表示せず、全指解除・`pointercancel`・中断時は消去する。
- 合体・分裂、画面外消失、強い反射、高速回転、激しい振動を起こさない。
- 通常時の傾き加速度72、最大速度126を維持し、初版比約1.5倍の体感速度とする。
- 無音で成立させ、説明、スコア、ランキング、複雑な設定を子ども画面へ置かない。

## ジェリー表現

- 少数のベジェ曲線で、厚みを保った不定形の半固形ボディを描く。細長い紐状にはしない。
- 半透明の多段グラデーション、内部のぼかしたハイライト、外周と内部の濃淡差、やわらかい輪郭線で透明感と厚みを出す。
- 移動方向へ穏やかに伸ばし、後端遅れと低周波の小さな非対称を残す。
- 方向転換では角度を瞬時に切り替えず、1フレームの最大角度変化を制限する。方向差が大きいほど`turnSoftness`を高め、伸びを一時的に弱めて丸みを通りながら向きを変える。
- 回転そのものはジェリーキャラクターの身振りとして許容する。ただし固体の楕円が高速回転する見え方や、顔の上下反転は避ける。
- 方向転換、壁、ジェリー同士の接触は`jellyPulse`へ変換し、短く遅れて戻る「ぷるん」「むにっ」を加える。跳ね返りは穏やかに保つ。
- 顔は外部画像や独立DOMを使わず同じCanvasへ描く。目2つと小さな口を控えめな大きさ・透明度で表示し、伸縮・圧縮へ追従させる。回転は小幅に制限して世界座標でほぼ正立させる。
- 表情は静止時と傾き移動中の小さな笑顔を基準とし、長押し成立中だけ、2本の三次ベジェからなる単一の閉じた口パスを数字の0に近い小さな縦長口へ連続変形する。速度、壁接触、ジェリー同士の接触は0口の条件にしない。長押し中は傾きが併存しても0口を優先し、解除後は穏やかに笑顔へ戻す。

## 操作、許可、安全性

- iOSで許可APIが必要な場合だけ、保護者向けの簡潔な許可導線を表示し、許可を繰り返し要求しない。
- 起動・復帰時は許可APIが存在してもボタンを先に表示せず、listenerを登録して約600ms実イベントを待つ。有効値を取得できればそのまま`active`とし、取得できない場合だけ許可ボタンを表示する。
- `requestPermission()`は許可ボタンのユーザー操作時だけ呼び出す。許可済みを独自保存せず、毎回ブラウザから届く実イベントで利用可否を判断する。
- 許可後は最大2.5秒有効値を待つ。拒否、例外、値欠落、非対応はエラー終了せず長押しfallbackとする。確認中も長押し操作を妨げない。
- `deviceorientation` listenerは重複登録しない。短時間プローブと取得失敗判定のタイマーは一元管理し、非表示・`pagehide`で破棄、表示・`pageshow`で置換して再判定する。
- センサー値には上限、デッドゾーン、平滑化を適用し、異常値や急変で跳ねさせない。
- `safe-area-inset-*`、`100dvh`、縦横回転、タブレット、`pointercancel`、高速タップ、複数指へ対応する。
- `visibilitychange`、`pagehide`で演算を止め、一時的な入力とジェリー弾性状態を破棄する。`pageshow`とBFCache復帰後もRAFを1本だけ再開する。
- `prefers-reduced-motion`では速度、慣性、伸び、尾、角速度、弾性パルス、反発を弱める。遊び自体は停止しない。
- 呼び寄せサインは入力重心の10px上を視覚中心とし、通常は中心近くの太く濃い波紋と、外側の細く薄い波紋、半径70pxの段階的に消えるオーラを描く。各波紋は外へ広がるほど透明度を下げ、指で中心を覆っても外周が見える範囲を保つ。
- reduced-motionでも傾きのみは笑顔、長押し中だけ控えめな0口とする。呼び寄せサインの立ち上がり、リング数と広がり、0口の最大量を抑えるが、リングは半径38〜54pxを保つ。
- 強い点滅、全画面フラッシュ、激しい揺れ、突然の大音量を使用しない。

## 実装とデータ

- HTML、CSS、Vanilla JavaScript、Canvasを使用し、外部物理・流体ライブラリを追加しない。
- 3体だけを単一`requestAnimationFrame`で更新し、フレーム時間へ安全な上限を設ける。
- 初期生成とリサイズで共通の基準半径とサイズ比を使用し、画面回転後も大・中・小の関係を維持する。接触判定は各体の半径和を使用する。
- 傾きと長押しを共通の力ベクトルへ変換する。物理移動と見た目の変形状態を分離する。
- スコア、履歴、位置、センサー値、タッチ位置を保存・カスタム送信しない。
- 正式公開前のため、ポータル、GA4、Clarity、共通ホームは追加しない。

## テスト

- 傾き、センサー拒否／非対応、長押し、短い慣性、複数指重心、`pointercancel`、高速60入力を確認する。
- 呼び寄せサインが長押し成立後だけ重心1点へ表示され、内側より外側の線幅と透明度が弱く、傾きのみでは出ず、解除・`pointercancel`・中断時に残らないことを確認する。
- 静止、低速／高速の傾き、壁／相互接触では笑顔を維持し、長押し成立時だけ波紋と同時に0口へ移ることを確認する。長押し中の傾きでは0口を維持し、解除・`pointercancel`後は滑らかに笑顔へ戻り、中断・BFCache復帰時に状態を残さない。
- 許可APIあり／なしそれぞれで、起動直後の有効イベント、イベント欠落、granted、denied、再初期化を確認する。listenerが1本、センサータイマーが重複せず、中断時にゼロになることを確認する。
- 左右、上下、斜め、約90度、連続切り返しで、角速度上限、方向転換中の丸み、新方向への再伸長、NaNなしを確認する。
- 高速回転、顔の上下反転、硬いボール反射、合体・分裂、画面外消失がないことを確認する。
- 壁接触とジェリー同士の接触で、穏やかな圧縮と弾性パルスが発生することを確認する。
- 半透明の本体、内部ハイライト、やわらかい輪郭、控えめな顔が3体すべてに描かれることを確認する。
- 赤・青・黄の半径比が3画面サイズで維持され、初期重なり、壁への継続的なめり込み、黄の顔や質感の視認性低下がないことを確認する。
- 縦→横→縦、390×844、844×390、1024×768で不要スクロールと表示崩れがないことを確認する。
- 中断・BFCache復帰、reduced-motion、2分相当の連続動作後も3体、Canvas 1枚、RAF 1本を維持する。
- JavaScript構文、既存回帰、コンソールエラー／警告、`git diff --check`を確認する。
- iPhone／Androidの実センサー、許可表示、透明感、回転の見え方、発熱、幼児の反応は実機確認待ちとする。

## MVP完了条件

1. 3色3体のジェリーが安定表示される。
2. 傾き、または長押し代替で自然に動き、初版比約1.5倍の反応を維持する。
3. 移動、方向転換、停止、壁・相互接触が、やわらかい半固形キャラクターとして見える。
4. 顔が控えめに変形へ追従し、上下逆や高速回転に見えない。
5. 合体・分裂、画面外消失、強い刺激、状態増殖がない。
6. 安全性、アクセシビリティ、ライフサイクル、レスポンシブ要件を満たす。
