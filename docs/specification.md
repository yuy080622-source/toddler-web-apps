# PRJ-003 共通仕様

## 共通ポータル試作

- Repositoryルートを、正式公開PASS済みアプリを選ぶ共通入口とする。
- 試作時点ではAPP-002、APP-003、APP-006のみ表示し、未公開アプリや準備中カードは表示しない。
- 大きな正方形アイコンと短い名称をカード全体のリンクとし、標準の縦スクロールで選べるようにする。
- アプリ一覧はデータ追加で増やせる構造とし、各アプリは独立したHTML／JavaScriptのまま維持する。
- 各アプリ上部のホームボタンは約2秒の長押し完了時だけポータルへ戻り、短押し、途中離し、領域外移動、`pointercancel`では遷移しない。
- ポータルは試作版とし、実機確認後にカードサイズ、列数、スクロール感を再判断する。

## 利用分析

- Microsoft Clarity Project ID `y7wygqymd5`をPRJ-003全体で1つだけ使用する。
- 共通ポータルと正式公開済みAPPをURLパス別に分析し、セッション録画とヒートマップを中心に利用傾向を確認する。
- 初期導入ではカスタムイベントとカスタムユーザーIDを使用しない。
- 氏名、メールアドレス、端末固有ID、子どもを識別する情報を新規取得しない。
- 個人情報入力、ログイン、フォーム、広告SDK、他の分析SDKを追加しない。
- 外部送信を伴う利用分析はPMが明示承認したPRJ-003用Clarityに限定する。
- 将来正式公開されたAPPも同じClarity Projectへ追加する。

## 基本UX

- 大きなタップ対象を使用する。
- 1画面1アクションを中心とし、幼児が選択肢を理解しなくても遊べるようにする。
- 小さなボタン、複雑なメニュー、誤操作を誘発する操作を避ける。
- タッチ直後に、音・動き・視覚反応のいずれかを返す。
- 不正解、減点、強いペナルティ、競争を設けない。
- 子ども画面にスコア、回数、ランキングを原則表示しない。
- 必要な利用情報や設定は保護者領域へ分離する。

## 安全性

- 強い点滅、全画面フラッシュ、激しい揺れを使用しない。
- 突然の大音量や驚かせる音を使用しない。
- 連打・複数指で音が過度に重ならないよう上限や間隔を設ける。
- `prefers-reduced-motion`時は粒子数、移動、揺れ、繰り返し演出などの刺激を弱める。
- 時間到達を失敗扱いせず、穏やかなおしまい演出を行う。

## 画面・操作

- スマートフォンとタブレットを優先する。
- 縦向き、横向き、レスポンシブ表示へ対応する。
- safe areaと`100dvh`を考慮する。
- Pointer Eventsを基本とする。
- 連打、複数指、途中退出、バックグラウンド化、復帰で破綻しない。
- 色だけで重要な状態を伝えず、形、文字、アイコン、ARIA属性等を併用する。
- 可能な範囲でキーボード操作を提供する。

## 音

- 初回利用時の既定値は音ONとする。
- 音OFFでも基本操作と視覚的な遊びが成立する。
- 音OFFは`localStorage`等の端末内保存を基本とする。
- 保存不可環境や音声API非対応環境でもアプリ本体を停止させない。
- 正式画像・正式音源は、必要性が高いアプリから段階的に導入する。
- 素材がない段階でも、絵文字、CSS、Web Audio API、許容可能な読み上げ等のフォールバックでMVPを成立させる。

## 子ども画面で禁止するもの

- 広告
- 外部リンク
- チャット
- 個人情報入力
- ログイン
- 購入・課金ボタン
- 発達や能力を断定する評価表示

## 保護者領域

- APP-007の時間設定は保護者向け任意機能とする。
- 利用統計を扱う場合は子ども画面へ出さず、保護者領域のみとする。
- アプリ独自の利用統計は端末内保存を基本とし、PM承認済みの共通Clarity分析を除いて外部送信しない。
- 統計を発達評価や診断に使用しない旨を明記する。
