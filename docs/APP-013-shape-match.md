# APP-013 かたちポン！ 仕様・設計

更新日：2026-10-02
状態：MVP試作実装済み・iPhone実機確認／PM操作感承認待ち

## 目的

1歳半〜2歳前後の幼児が、説明文を読まずに「形を持つ → 同じ形へ運ぶ → 入る」という因果を楽しめるドラッグ型Webアプリを作る。

知識テストや正誤判定を主目的にせず、形の違いに気づきながら指で物を運ぶ遊びそのものを中心にする。

## 対象年齢

- 主対象：1歳6か月〜2歳
- 大人の説明なしでも触って反応を理解できることを優先する

## 利用端末

- スマートフォン・タブレット
- iPhone Safariを優先して実機確認する
- 縦向き・横向き・タブレットへレスポンシブ対応する

## MVPの基本操作

- 画面には大きな「○・□・△」の3ピースと、それぞれに対応する3つの大きな型を表示する
- ピースを指でドラッグする
- 同じ形の型へ十分近づけて指を離すと、ピースが吸い込まれるようにスナップして収まる
- 精密な位置合わせは要求しない。幼児向けに判定範囲を見た目より広く取る
- 間違った場所や別の形で指を離した場合は、不正解表示を出さず、ピースが元の位置へやさしく戻る
- 配置済みピースはそのラウンド中は固定する
- 3つすべて入ると、短い穏やかな「できた」演出後に同じ遊びを再開できる状態へ自動リセットする
- スコア、回数、制限時間、ランキングは表示しない

## 画面構成

- 上〜中央：3つの大きな型
- 下側：3つの大きな可動ピース
- 子ども向け説明文、メニュー、設定、広告、外部リンクは置かない
- 背景は明るく低刺激な単色〜ごく弱いグラデーション
- ピースと型は形状そのものに加え、色・明暗差でも見分けやすくする。ただし色だけに依存しない

## ピース

- ○：コーラル系
- □：ブルー系
- △：イエロー系
- 1ピースの見た目サイズはスマートフォン縦画面で概ね88〜104pxを目安とする
- 最小でも幼児が狙いやすい大きさを維持する
- ドラッグ開始直後にわずかに持ち上がる／大きくなる反応を返す
- 指の真下に完全に隠れないよう、必要ならドラッグ中のみ数px上へ補正してよい

## 型

- 各ピースより少し大きい
- 形の輪郭と薄い面で「ここに入る」ことが分かる見た目にする
- 正しいピースが判定範囲へ入ったときだけ、型をわずかに明るくする／拡大するなど控えめな予告反応を返す
- 間違ったピースが近づいても赤表示、×、警告音、揺れなどの否定表現はしない

## 正しく入ったとき

- ピースを型中央へ短くスナップさせる
- 1回だけ小さく「ぽん」と弾むような視覚演出を返す
- 周囲に2〜4個程度の小さな光点やリングを出してもよい
- 強いフラッシュ、紙吹雪大量表示、画面揺れは使用しない
- MVPは無音で成立させる。効果音は実機確認後の追加候補とする

## 間違った場所へ置いたとき

- 不正解扱いをしない
- 元位置へ200〜350ms程度でやさしく戻す
- 赤色、×、減点、ブザー、強い振動などは使用しない
- 戻る動き自体を「もう一度触れる状態へ戻す」ための自然な処理とする

## ラウンド完了

- 3つすべて入ったら、3ピースまたは型が1回だけ小さく弾む程度の穏やかな完了演出を行う
- 約0.8〜1.3秒後に次ラウンドへ戻す
- 次ラウンドでも操作方法は変えない
- MVPでは難易度上昇、形追加、速度変化を行わない

## 複数指・連打

- 別々のピースであれば複数指で同時に触れても破綻しない
- 1つのピースは1つのpointerIdだけが操作権を持つ
- 同じピースへの追加pointerは無視する
- pointerup、pointercancel、lostpointercaptureで操作状態を必ず解放する
- 完了演出中の入力でタイマーやDOMが増殖しないようにする

## アニメーション

- ドラッグ中：即時追従
- 正解スナップ：短く滑らか
- 失敗時の戻り：やさしい短時間移動
- 完了演出：1回だけ
- prefers-reduced-motion時は、スナップ・戻りを短くし、弾みや粒子を停止または最小化する
- reduced-motionでも「正しく入った」「元へ戻った」が分かること

## 技術設計

- HTML / CSS / Vanilla JavaScript
- 外部ライブラリなし
- 固定数のDOM要素で構成し、ドラッグごとに要素を追加しない
- Pointer Eventsを使用する
- CSS transform中心で移動し、毎フレームDOM生成をしない
- 各ピースに開始位置、現在位置、対応target、activePointerId、placed状態を持たせる
- target判定はピース中心とtarget中心の距離、または十分広い矩形／形状領域で行い、精密な輪郭一致は要求しない
- ラウンドリセット用タイマーは最大1本とし、中断・再開時に残留させない
- 画面回転・resize後は、未配置ピースを安全な開始位置へ再配置し、配置済みピースは対応target中央へ再計算する

## 中断・復帰

- visibilitychange / pagehideでactive pointer状態と一時演出を解除する
- pageshow / BFCache復帰時に二重イベントや二重タイマーを作らない
- 中断中にラウンド完了タイマーが残らない
- 復帰時は操作可能な安定状態へ戻す

## レスポンシブ

- 390×844
- 844×390
- 1024×768
を最低確認サイズとする

- safe area内に収める
- 100dvhを使用する
- 横スクロールを発生させない
- 3ピースと3targetが重ならず、最小タップ／ドラッグ領域を維持する

## アクセシビリティ

- 色だけで正しい組み合わせを表現しない
- 各ピースは形状で識別できる
- aria-label等は付与してよいが、子ども画面へ説明文を増やさない
- reduced-motionに対応する
- 音声OFFでも全操作が成立する（MVPは無音）

## 保存データ・外部通信

- MVPでは保存データなし
- ログインなし
- 個人情報入力なし
- 外部通信なし
- GA4 / Clarity / 共通ホーム / ポータル / ConoHa正式公開はMVP実機確認後に別判断する

## MVPテスト

- ○・□・△それぞれの正解ドラッグ
- 別targetへのドロップ→穏やかに元へ戻る
- target外ドロップ→元へ戻る
- target判定が厳しすぎない
- 3つ配置→完了演出→リセット
- 完了直前の高速入力
- 2〜3本指で別ピースを同時操作
- 同一ピースへの複数pointer
- pointercancel / lostpointercapture
- 連続50回以上の操作
- 画面回転
- resize
- visibilitychange
- pagehide / pageshow
- BFCache
- prefers-reduced-motion
- 390×844 / 844×390 / 1024×768
- 不要スクロールなし
- DOM・タイマー増殖なし
- console error / warningなし
- 2〜3分程度の連続動作
