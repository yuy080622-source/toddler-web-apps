# PRJ-003 変更履歴

## 2026-08-23 — APP-006 打ち上げ演出改善のPM判断

### 背景

- 既存APP-006は、タップした位置で直接花火が開く方式だった
- レビューで「打ち上げ花火として、画面下から上がってから開く方が全体像を理解しやすい」という意見が出た
- 幼児向けの即時反応を損なわず、花火らしさを上げる改善として採用した

### PM判断

- 打ち上げ開始位置は画面下端より少し下
- 地面・街並みは今回追加しない
- タップX座標は基本維持
- タップY座標は基本維持するが、上端・下端だけ安全範囲へ補正
- 上端は画面上端から約10%より下を目安
- 下端は画面高さ約70%より上を最低爆発高度の目安
- 画面下部タップ時もX位置は維持し、Yだけ最低高度まで上げる
- タップ直後に打ち上げ反応を開始し、約0.3〜0.5秒で爆発位置へ到達
- 打ち上げ表現は小さな光の玉＋短い尾
- 上昇音は追加せず、既存花火効果音のみ
- 既存の粒子上限200、同時効果音最大4、音OFF保存、中断・復帰処理を維持
- `prefers-reduced-motion`では打ち上げ時間・移動・尾を短くし、既存の粒子数・寿命・発光低減も維持
- 強い点滅、全画面フラッシュ、突然の大音量は追加しない

### Before記録

- 改善前のiPhone縦画面録画を取得済み
- 約10.8秒
- 旧仕様「タップ位置で直接花火が開く」状態
- Google Drive保存済み
- 素材ログ`MAT-20260823-016`へ紐付け済み
- Afterは新仕様実装後、同程度の長さで上部・中央・下部タップを含めて撮影する

### 状態

- GitHub正式資料へ反映済み
- 実装はCodex待ち

## 2026-08-23 — APP-002 公開前コード検証

### 修正

- 音OFF設定を`localStorage`へ保存し、保存不可時のフォールバックを追加
- 効果音の同時再生を最大4音へ制限
- 終了したOscillator、Gain、Filterの追跡・切断処理を追加
- 音OFF、タブ非表示、途中退出時に再生中の効果音を停止
- `visibilitychange`、`pagehide`、`pageshow`へ対応し、BFCache復帰時に生成を1つだけ再開
- 非表示・退出時に生成タイマー、削除タイマー、泡、光粒、文字DOMを消去
- キーボードフォーカス中の泡を一時停止し、画面外へ消える問題を修正
- フォーカス中の泡を割った場合、遊び領域へフォーカスを戻す処理を追加

### 検証

- 390×844px縦画面、844×390px横画面、1024×768pxタブレット相当で縦横スクロールなし
- 泡72〜130px、音ボタン66〜72px、最大泡数10を確認
- 同じ泡への5回同時相当操作が1回だけ計上されることを確認
- 別々の2泡への同時相当操作が2回計上されることを確認
- 音OFFと再読み込み後の設定維持を確認
- 音あり高速操作後に光粒・文字DOMが残らないことを確認
- BFCache相当の途中退出・復帰後に泡生成と音設定が正常なことを確認
- 60秒超の連続動作後も泡が上限内で循環し、一時DOMが残らないことを確認
- Enterキー操作、フォーカス中の泡停止、破裂後のフォーカス復帰を確認
- JavaScript構文、コンソールエラー・警告なし

### 判定・保留

- コード上の技術検証はPASS
- 実際の複数指、音量・音質、safe area、reduced-motion、刺激、発熱は実機確認待ち
- 子ども画面の回数表示はPRJ-003共通仕様と衝突するため、削除せずPM判断待ち
