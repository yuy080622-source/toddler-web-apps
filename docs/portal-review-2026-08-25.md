# PRJ-003 共通ポータル iPhone実機レビュー

確認日: 2026-08-25

## 判定

**PASS / 正式採用**

Repositoryルートの共通ポータル試作版をiPhone実機で確認し、現在の基本UIとホーム導線を正式採用とする。

## 正式採用した仕様

- 正式公開PASS済みアプリのみ表示する
- APP-002 / APP-003 / APP-006を初期表示対象とする
- スマートフォン縦は2列
- スマートフォン横は3列
- タブレットは3〜4列
- 大きな正方形アイコン＋下部の短いアプリ名
- ブラウザ標準の縦スクロールを使う
- 未公開アプリや「準備中」カードは子ども画面に出さない
- 各アプリの共通ホームボタンは短押しでは戻らず、約2秒長押し完了時だけポータルへ戻る
- 長押し途中解除、領域外移動、pointercancel等はキャンセルする
- safe area、100dvh、prefers-reduced-motionを維持する

## iPhone実機結果

- 縦画面2列のカードサイズ、間隔、名称視認性: PASS
- 標準縦スクロール: PASS
- スクロール時の誤タップ: 問題なし
- ホーム短押し: PASS（非遷移）
- 約1秒で指を離す途中キャンセル: PASS
- 約2秒長押し: PASS（ポータルへ復帰）
- 縦→横→縦の回転: PASS
- 横画面3列: PASS
- APP-002 / 003 / 006のホームボタン配置とsafe area: PASS
