# PRJ-003 プロジェクト背景

## 目的

PRJ-003は、1〜2歳前後の子どもが保護者と一緒に、読む力や正解選択を前提とせず、タッチ直後の色・動き・音を楽しめるWebアプリ群です。

広告、課金、ログイン、個人情報入力に依存せず、スマートフォンやタブレットのブラウザで短時間から遊べることを目指します。

## 対象ユーザー

- 1〜2歳前後の子ども
- 子どもと一緒に遊ぶ保護者
- スマートフォン・タブレット利用者

2. APP-003 くだものポン！

8. APP-010 リキッドあそび（仮）— MVP仕様確定・実装待ち

デスクトップの旧`Fashion`フォルダに残る動物タッチ旧版は、現行制作物に含めません。

## 管理方針

- `toddler-web-apps` GitHub Repositoryを正式な共通参照点とする。
- 仕様は`docs/specification.md`、技術方針は`docs/design.md`を参照する。
- 作業終了時の現在状態は`docs/handoff.md`へ反映する。
- 重要変更は`docs/changelog.md`へ記録する。
- 当面、移行元のデスクトップフォルダをバックアップとして残す。

## 公開方針

- 静的アプリはGitHub Pagesを第一候補とする。
- 正式公開PASS済みのAPPだけを共通ポータルへ表示する。
- APP-002、APP-003、APP-004、APP-006は正式公開済み。
- APP-010は独立ディレクトリでMVPを実装し、コード・Pages検証後にiPhone／Android実機確認へ進める。
- 公開URLでの技術確認後、iPhone等の実機確認を行う。
